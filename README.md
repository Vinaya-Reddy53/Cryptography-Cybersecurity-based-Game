The Cryptography Game is a beginner-friendly application designed to make learning basic cryptography concepts more interactive.
Players are presented with encrypted messages and challenges where they need to identify or recover the original message. The application provides a graphical interface, validates user responses, and keeps track of the player's score.
Designed to teach fundamental concepts such as encryption, decryption, ciphers, keys, and plaintext/ciphertext through an interactive game.
It involves 3 missions with different phases.
Technologies Used:
Python
PyQt6
Cryptography concepts
Caesar Cipher
ROT13
log Tables
